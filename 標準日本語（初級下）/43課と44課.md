## 文法

### 使役形式

1. 要求、命令或强迫他人做事。
2. 促使某事实现。经常使用无对应他动词的自动词 e.g. 太る、騒ぐ、成功する、光る。
3. 导致某事发生。 e.g. 怒る、困る、待つ、死ぬ、泣く、心配する。

ウ→ ア＋せる

る→~~る~~させる

する→させる　　来る→来させる

Nは/がNをV~自~させる。 [大部分自动词]

1. 社長は李さんを出張させます。
2. 先生は質問に答えられない学生を立たせることがあります。
3. 先生は病気の李さんを家へ帰させました。

Nは/がNにNをV~他~させる。[他动词和移动性自动词(e.g.渡る)]

1. 部長は部下にレポートを作らせます。

### 使役被动形式

ウ→ ア＋せられる  す结尾的动词要用这个

ウ→ ア＋される　不是す结尾的动词

る→~~る~~させられる

する→させられる　　来る→来させられる

### （さ）せてください

请求别人允许自己做某事。

1. （私に）仕事をやらせてくだい。
2. 寝させてくださいよ。
3. 少し休ませてください。

（さ）せてもらえますか

（さ）せていただけませんか

（さ）せてくださいませんか

### 連用形 + やすい / にくい

易于/难于....

1. このボールペンはとても書きやすいです。
2. そのパソコンは使いにくかったです。

### のではないでしょうか

“难道不是...吗？” 委婉表达

1. 東野圭吾の小説は面白い　のではないでしょうか。・んではないでしょうか。

### ぐっと

表示变化幅度大，动作迅猛。





1. 动词原形+つもり　打算...
2. しかも　而且
3. 例えば　for example
4. そこで　so, then
5. ことにする 个人决定　ことになる 多方决定　ようになる 发生了某种变化

## 文法

### ようだ

将五官感觉作为依据进行推测，带有一定的主观色彩。

Aい / NA+な / N+の / V~简~        +       ようだ

1. 明日雨が降るようです。　明天好像要下雨。
   1. 雨が降りそうです。要有视觉信息，看起来要下雨了
2. 息子の受験勉強は疲れるようです。　じゅけんべんきょう：应试学习

### みたいだ

将五官感觉作为依据进行推测，带有一定的主观色彩。***一般在口语中使用。***

Aい / NA / N / V~简~        +       みたいだ

1. 佐藤さんはそのケーキを一口も食べなかった、好きじゃないみたいだ。

### らしい

根据外部信息或者可观察的事物进行推测，更加客观。也可以用来婉转叙述听来的信息。

Aい / NA / N / V~简~        +       らしい

らしくない　らしかった　らしかなかった　らしくて

1. 天気予報によると、午後は雨らしい。
2. 見に来る人がいっぱいいる。この映画は面白いらしい。
3. あの話は本当らしい。
4. 先生は七月の末(すえ)に日本に行くらしい。

### 過ぎる

表示动作或者事物的性质超过了正常的量或者程度。常常带有谴责、遗憾、后悔等情绪。“太...”，“过于...”

V~連用形~ / A~~い~~ / NA  + 過ぎる

1. この子は痩せ過ぎる。
2. 早すぎませんか。
3. コーヒーに砂糖を入れ過ぎた。
4. この問題は複雑すぎて、私には答えられない。这个问题太复杂了，我回答不了。

楽しみ：有期待的意思

重い　重さ　重み

痛い　痛み
