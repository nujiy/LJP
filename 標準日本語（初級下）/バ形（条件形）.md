# バ形（条件形）

## 基本变化规则

### 形容词（A）
1. **い形容词**：A~~い~~　→　Aければ
   - 高い → 高ければ
   - 安い → 安ければ
   - 大きい → 大きければ

2. **な形容词（NA）/ 名词**：
   - NAであれば
   - NAならば（更常用）
   - 例：静か → 静かであれば / 静かならば

### 动词（V）
1. **五段动词**：ウ→エ＋ば
   - 書く → 書けば
   - 話す → 話せば
   - 待つ → 待てば

2. **一段动词**：~~る~~→れば
   - 見る → 見れば
   - 食べる → 食べれば
   - 寝る → 寝れば

3. **特殊动词**：
   - する → すれば
   - くる → くれば

## 用法

### 1. 假设条件（如果...的话）
- もし雨が降れば、試合は中止になります。
- 時間があれば、映画を見に行きましょう。
- 安ければ、買います。

### 2. 一般性条件（每当...的时候）
- 春になれば、桜が咲きます。
- このボタンを押せば、ドアが開きます。

### 3. 习惯性条件
- 暇があれば、本を読みます。
- お金があれば、旅行に行きます。

## 注意事项

1. **ば形表示客观条件**，不表示说话人的意志或希望
2. **ば形后不能用命令形、意志形**
3. **ば形比たら形更正式**，多用于书面语
4. **ば形表示必然的结果**，たら形可以表示偶然的结果

## 常见例句

- 天気が良ければ、散歩に行きます。
- お金があれば、車を買います。
- 時間があれば、手伝ってください。
- この薬を飲めば、熱が下がります。
- 春になれば、花が咲きます。
- 体が丈夫なら、どんな仕事でもできる。
